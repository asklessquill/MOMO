# MOMO System v0.5 — Closeout Criteria

Status: **DRAFT / PREPARED DURING PHASE 6 REVIEW WAIT / NOT YET CLOSED**

v0.5 is not closed by Phase 6 review PASS alone. Phase 6 PASS proves the frozen pre-acceptance candidate is semantically coherent. Release closeout requires that the reviewed meaning become Current, that Current can be recovered by a fresh Actor, and that formerly independent responsibility repositories have explicit durable dispositions.

## Mandatory closeout gates

All must hold:

1. **Phase 6 independent pre-acceptance review = PASS** against the exact frozen targets, with the result durably recorded.
2. **Human activation decision** is explicit. Review PASS is recommendation evidence, not activation authority.
3. **Pre-activation drift gate = clear**: any material semantic drift is re-reviewed; non-material capability/evidence drift is preserved and reconciled.
4. **Phase 7 activation = PASS**: v0.5 Current meaning is activated with rollback refs, exact before/after SHAs, no unreviewed constitutional redesign, and post-write semantic verification.
5. **Phase 8 Fresh Actor recovery = PASS**: a fresh Actor recovers v0.5, exactly five responsibility-bearing Actors, Human sovereignty, owner/module relationships and STOP/HUMAN_GATE without Builder correction.
6. **Final independent review = PASS** over the activated Current state and Phase 8 recovery receipt. This review checks that activation did not introduce semantic drift not covered by the pre-acceptance review.
7. **Phase 9 disposition receipt exists** for MOMO-Observatory, references, Dango, FROG and SandFrog. Physical deletion is not required; retained owner-controlled module/archive is a valid final disposition.
8. **Phase 0 disposition is explicit**. Mechanical recovery insurance may PASS later or remain a Human-accepted residual risk, but closeout must not falsely report it as verified if evidence does not prove it.
9. **No unbounded authority is created**: MOMO is not Human/Supervisor; KIBI is not orchestrator; routing/evidence does not create Task authority; FROG/SandFrog history does not create replay/external-mutation authority; SARU remains bounded by Human authority.
10. **Durable closeout receipt** records release identity `v0.5`, activated SHAs, review receipts, recovery receipt, module dispositions, residual risks and explicit STOP.

## What Phase 9 does not require

v0.5 does **not** require every former repository to be deleted, merged, archived by GitHub settings, or made physically inaccessible.

The constitutional requirement is responsibility convergence:

- MOMO-Observatory / references -> MOMO responsibility;
- Dango -> INNU responsibility;
- FROG / SandFrog -> SARU responsibility.

A technically separate repository may remain if it is explicitly recovered as an owner-controlled module/evidence store rather than a sixth Actor or independent Current authority.

## Closeout state

When all mandatory gates are satisfied, write exactly:

`MOMO SYSTEM v0.5 CLOSED / CURRENT / RECOVERABLE / STOP`

The closeout itself commissions no v1, no next milestone, no experiment, no autonomous cycle and no external action.
