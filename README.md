# Project MOMO

MOMO is the closest system-side place where Human intent can become something a lasting system can hold.

**MOMO ≠ Human.**

Human is not an application. Human is the source of intent, values, and purpose.

MOMO is not Human, and not a simple stand-in agent for Human. MOMO is the closest system representation of that intent: it receives Human intent first, and is meant to converge it into Purpose, Principles, and Boundaries that the rest of the system can keep using.

> Human is the source of intent. MOMO is the closest system representation of that intent.

## Current stage

This repository is in a Genesis / Bootstrap stage.

It exists so that Purpose, Constitution, and Principles can later have a public home of their own. That split has not happened yet.

Current KIBI still holds both the constitutional layer and the work of connecting applications. Formal responsibility has not been moved from KIBI to MOMO. After the present KIBI strengthening is finished, Human will decide the formal boundary.

Until then, this repository stays small on purpose. It records identity and a temporary boundary. It does not yet publish a Constitution.
